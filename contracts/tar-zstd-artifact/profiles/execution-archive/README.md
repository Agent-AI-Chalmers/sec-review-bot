# Execution Archive

Language: English | [中文](README.zh.md)

This directory defines the archive published after one review execution completes. It is a profile over the shared [envelope v1](../../envelope/v1/SPEC.md), not part of the Execution API contract.

- [v1/SPEC.md](v1/SPEC.md) defines the internal tree and manifest relationships.
- [v1/corpus](v1/corpus) contains real archives that every execution-archive consumer executes in addition to the shared envelope corpus.
