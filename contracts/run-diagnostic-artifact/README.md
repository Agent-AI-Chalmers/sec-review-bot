# Run Diagnostic Artifact

Language: English | [中文](README.zh.md)

This family defines the archive published for one completed review run. It is a profile over the shared [tar-zstd-artifact v1 envelope](../tar-zstd-artifact/v1/SPEC.md), not part of the Execution API contract.

- [v1/SPEC.md](v1/SPEC.md) defines the internal tree and manifest relationships.
- Producer and consumer behavior is covered by the package-local diagnostic bundle tests; the shared envelope corpus is owned by `tar-zstd-artifact`.
