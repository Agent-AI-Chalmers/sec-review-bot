# Agent 执行轨迹

语言：[English](README.md) | 中文

本契约定义 Agent 运行时、记忆读取工具、控制台和用量统计脚本共用的 JSONL 执行轨迹格式。

- [v1 规范](v1/SPEC.zh.md)说明记录内容和使用规则。
- [记录 schema](v1/schemas/record.schema.json)用于校验结构。
- [共享测试输入](v1/corpus/manifest.json)列出必须接受和拒绝的完整轨迹。

## 生成与读取要求

生成方按规范输出记录。读取方在使用前校验 JSONL 格式、记录结构、序号顺序、消息标识，以及已提供的调用关系是否一致。缺少结束记录可以表示执行中断；格式错误的记录则必须拒绝。

Python 和 TypeScript 的读取组件分别执行同一套测试输入。生成方测试也用 schema 校验输出。各包不读取其他包的测试目录。

本契约没有需要生成的派生文件，也没有专用生成工具。修改 schema、测试输入或规范时，应一起审查相关读取组件。

用量由生成方按统一口径转换。用量对象包含固定的六个字段，不允许额外字段；无法获得的值使用 `null`。读取方先校验这些标准字段，再进行统计。完整要求见 v1 规范。
