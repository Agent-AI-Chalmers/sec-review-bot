# Skill Source Notes

These notes trace bundled security rules to authoritative sources and record the limits of the supported inference.

They are intentionally kept outside `resources/skills/` so materialized agent skill views do not expose source lists to `/skills`. Each note should contain rule-to-source mappings, useful locators, applicability limits, and source review dates. Test cases, model runs, case IDs, coverage decisions, and admission history belong in their respective test or design documentation.
